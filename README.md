# 🎓 Campus Job

A full-stack campus recruitment platform built with React.js, Spring Boot, REST APIs, and MySQL. Campus Job connects students, recruiters, and administrators through a secure platform for job discovery, applications, candidate management, placement analytics, and role-based workflows.

### Tech Stack
React.js • Vite • Tailwind CSS • Java • Spring Boot • Spring Security • JWT • MySQL • JPA/Hibernate

### Key Features
- Student job discovery and application tracking
- Recruiter job posting and candidate management
- Admin dashboards, analytics, and user management
- Email/password authentication
- Google authentication
- Mobile OTP authentication
- Secure resume upload and access control
- Role-based authorization and recruiter isolation
